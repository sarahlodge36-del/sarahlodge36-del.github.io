# The AI Frontier — Exploring AI Today and Tomorrow

An interactive educational website exploring today's artificial intelligence assistants and the technologies shaping AI's future.

# Project Overview

The AI Frontier is a multi-page educational website designed to introduce visitors to artificial intelligence, explore existing AI assistants and encourage curiosity about future developments.

Visitors are welcomed by XGENFUTBOT, a virtual robot guide, before choosing between two main sections: AI Today and AI Tomorrow.

Why I built this: To combine my interest in artificial intelligence with my frontend development skills while creating an engaging, accessible learning experience.

# Features

## AI Today

- ChatGPT

- Claude

- Gemini

- Challenges and Problem-Solving

- Browser Speech Behaviour

XGENFUTBOT uses JavaScript's Speech Synthesis API to deliver a spoken introduction.

During testing, I discovered that speech initiated automatically on page load can behave inconsistently depending on browser restrictions.

By testing the speech function independently through the browser console, I was able to confirm that the speech functionality itself worked.

What I learned: Debugging involves isolating individual features and distinguishing between code issues and browser behaviour.
